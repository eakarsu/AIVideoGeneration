# Operations

Copy `.env.example` to `.env`, replace placeholders, provision PostgreSQL/dependencies, then run `cd backend && npm run migrate`. Start with `./start.sh`.

Startup does not mutate the database or host. Run `npm test` in `backend`. Stock libraries, storage/CDN, transcription, translation, rendering, YouTube, TikTok, and other publishing targets are typed delivery contracts only. A verified adapter acknowledgement plus human rights/consent/moderation review is required before treating output as published or cleared. Deterministic export hashes and accessibility/brand checks are application evidence, not external certification.

The legacy seed deletes demo rows and is guarded by `ALLOW_DESTRUCTIVE_DEMO_SEED=true`; use it only for an isolated disposable database.
